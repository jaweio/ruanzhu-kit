4. **本地数据管理层**:以 RoleDB、BagDB、MailDB、TaskDB、PetDB、SceneDB 等数
据库对象管理玩家镜像数据,配合服务器时间同步(ServerTimeDB)保证数据一致性。
5. **完善的异常与合规体系**:统一错误码(ErrorCodeConst)覆盖货币不足、等级限制、
模块未开放、账号封禁、敏感词、实名与充值限额等业务异常场景。
6. **实时开发工作流**:配套常驻增量编译脚本,代码保存后 1-4 秒完成增量编译,支撑高
频迭代开发。

# 软件架构
## 2.1 总体架构
客户端采用分层架构,自上而下分为表现层、业务模块层、数据层、网络层与基础框架层:
- **表现层**:基于 Egret 显示列表与 Morn UI 组件库(core/morn)构建界面,统一由视
图类(View)负责界面渲染与交互响应。
- **业务模块层**:`src/sango/module/` 下按业务域划分的 60 余个模块目录,每个模块
包含模块类(Module)、视图(View)与数据对象(DB)。
- **数据层**:`src/sango/db/` 提供玩家数据镜像对象与配置表访问
(`src/sango/tables/JsonTabs.ts` 统一装载 JSON 配置)。
- **网络层**:`src/sango/msg/` 的协议常量、消息接收与分发体系,底层使用 Egret 
socket 模块进行⻓连接通信。
- **基础框架层**:`src/core/asframe`(约 1.3 万行的自研框架库,含几何、集合、事件
等基础设施)、`src/core/components`(通用组件)与 Egret 引擎适配层。
