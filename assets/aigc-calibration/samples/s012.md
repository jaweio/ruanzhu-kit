限时活动背包道具通过专用协议(11401/21401)查询与领取。活动配置由服务端下发,客户
端按活动时间窗自动展示与隐藏活动入口,活动结束后入口自动下线,无需发版。
## 7.9 经济与商城系统
商城模块(shop)提供道具购买,商品配置由服务端下发;充值模块(recharge)对接渠道
支付,支付回调后由服务端发货入背包;兑换模块(exchange)提供货币与道具的相互兑
换;收益模块(income)管理离线收益、成⻓基金等收益类玩法的累计与领取;宝箱活动模
块(treasureBoxAct)提供开箱获取奖励玩法。
经济系统的全部数值变更(购买、充值发货、兑换、领取)均由服务端进行最终校验与记
账,客户端仅负责展示与请求发起,保障经济安全。
## 7.10 社交互动系统
聊天模块(chat)提供世界频道交流,支持聊天表情资源(由美术工单流程维护更新),发送
内容经敏感词校验(错误码 10038 敏感词非法);好友模块(friend)管理好友申请、添加、
删除与互动;邮件模块(mail,MailDB)承载系统邮件、运营邮件与附件领取,邮件状态
(已读、已领取)本地镜像同步;邀请模块(invite)支持邀请返利等社交裂变玩法;同伴模
块(peer)支持玩家互访与组队协作。
## 7.11 通信与框架支撑系统
网络协议层(msg)实现全部客户端—服务端通信:协议常量(MsgConst)集中定义协议
号,消息接收器(MsgRec,约 10900 行)完成服务端消息的结构化解码,消息分发层
(MsgFun、MsgRecFun)将消息路由至各业务处理函数,中心服功能消息按 centerFun 清
单路由(详⻅附录 C)。
运行时支撑包括:全局数据(GD)维护客户端全局状态与会话数据;会话管理(Session)
维护登录令牌与重连;世界管理(LegendWorld)控制游戏世界场景切换与生命周期;多语
言模块(Lang)管理界面文案的多语言装载与切换;基础设施层由 Morn UI 组件库与 
asframe 自研框架(几何、集合、事件系统)构成;红点系统(RedDotModule)集中管理
功能入口的待处理提示;模块注册器(RegModule)负责各业务模块的注册与生命周期调
度。
# 运维管理
## 8.1 日志与调试
客户端内置 DebugWin 调试窗口,可在运行期查看日志与内部状态;开发环境配合 mock 数
据(libs/mock)支持脱离服务端的界面调试。发布构建中调试入口默认关闭。
## 8.2 错误码体系
业务异常通过统一错误码表达,ErrorCodeConst 集中定义。代表性错误码如下:
| 错误码 | 含义 |
| --- | --- |
| 0 | 成功 |
| 10006 | 配置文件错误 |
| 10007 / 10008 | 金币不足 / 钻石不足 |
| 10009 | 材料不足 |
| 10014 | 模块未开放 |
| 10018 / 10020 | 账号已被封 / ⻆色已被封 |
| 10038 | 敏感词非法 |
| 10035 / 10036 / 10037 | 测试实名缺失 / 单笔充值限额 / 月充值限额 |
| 14026 | 超出每日招募上限 |
客户端依据错误码进行界面提示与流程控制,网络层异常由 PalNetError 统一处理并触发重
连流程。
## 8.3 会话与重连
Session 维护登录态与会话令牌;网络断开后客户端按策略自动重连并恢复会话,重连期间
界面进入等待状态,恢复后自动同步服务器时间(ServerTimeDB)与玩家数据镜像。
## 8.4 资源与性能管理
- **资源增量加载**:按资源组懒加载,降低首屏等待;
- **图集与⻣骼优化**:界面散图合并图集;武将与战斗动作采用 DragonBones ⻣骼动
画,控制资源体积与运行内存;
- **对象与事件治理**:模块卸载时清理事件监听,避免内存泄漏。
