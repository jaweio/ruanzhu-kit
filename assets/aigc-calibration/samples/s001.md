# 软件概述
## 1.1 软件简介
三国策略手游客户端软件(以下简称"本软件")是一款基于 TypeScript 语言与 Egret 引擎
(版本 5.2.17)开发的三国题材策略手机游戏客户端。客户端实现从账号登录、服务器选
择、⻆色创建,到武将招募、军队编成、阵法布置、回合制战斗、装备锻造、任务活动、商
城充值与社交互动的完整玩法体系,为玩家提供跨场景的策略对战与养成收集体验。
客户端与游戏服务端通过自定义二进制消息协议通信,本地负责界面渲染、交互响应、资源
管理与玩法流程编排,服务端负责数值校验与数据持久化。客户端源码规模约 27 万行 
TypeScript 代码,包含 1800 余个源文件,覆盖 60 余个业务功能模块。
## 1.2 建设目标
本软件的建设目标包括:
- **完整还原策略玩法闭环**:覆盖"登录—创⻆—招募—编队—布阵—战斗—结算—养
成"的核心游戏循环,保证玩家在无服务端人工干预的情况下完成全部主线流程。
- **流畅的移动端体验**:通过资源增量加载、图集合并、⻰⻣(DragonBones)⻣骼动画
与帧动画结合等手段,在中低端移动设备上保持稳定帧率。
- **可快速迭代的模块化架构**:业务功能以模块(Module)为单位组织,模块间通过全局
通知(Notice)与消息中心解耦,支持运营活动类功能的高频新增与下线。
- **多语言与合规支持**:内置多语言管理(Lang 模块)、敏感词校验、实名与未成年人充
值限制等合规能力,满足移动游戏上线运营要求。
## 1.3 软件特性
本软件具有以下主要特性:
1. **回合制策略战斗引擎**:战斗实体(BattleEntity)、战斗管理器(BattleMgr)与特效播
放器(BattleEffectPlayer)分层实现,支持技能释放、兵种克制、阵法加成与战斗波次
(BattleWave)编排。
2. **大规模模块化业务体系**:登录、⻆色、军队、竞技场、装备、锻造、坐骑、宠物、任
务、活动大厅、商城、充值、聊天、好友、邮件等 60 余个业务模块按统一规范注册与调
度。
3. **统一协议层**:协议常量(MsgConst,协议号 1xxxx 请求 / 2xxxx 应答)、消息接收器
(MsgRec)、消息分发(MsgFun/MsgRecFun)构成约 2.2 万行的网络协议处理层,覆盖
全部业务交互。
